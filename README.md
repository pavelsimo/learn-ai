# Learning AI

A collection of courses and notes on AI/ML topics, covering open-source models, transformers, and computer vision.

## Courses

### 1. [Open Source Models with Hugging Face](./01-open-source-models-hugging-face/)

Comprehensive guide to using Hugging Face transformers for various tasks including text generation, translation, speech recognition, and computer vision. Includes practical examples and code snippets.

**Topics covered:**
- Model checkpoints and safetensors format
- Transformers library pipelines
- Text generation, translation, and summarization
- Audio processing (ASR, TTS, zero-shot audio classification)
- Computer vision tasks (object detection, segmentation, depth estimation, image captioning)
- Multimodal models

### 2. [Attention in Transformers: Concepts and Code in PyTorch](./02-attention-transformers-pytorch/)

### 3. [Stanford CS231N - Convolutional Neural Networks for Visual Recognition](./03-stanford-cs231n/)

In-depth notes from Stanford's CS231N course covering fundamental and advanced concepts in computer vision and deep learning.

**Topics covered:**
- Python and NumPy fundamentals
- Image classification challenges and approaches
- K-Nearest Neighbors and linear classifiers
- Neural networks architecture and training
- Convolutional Neural Networks (CNNs)
- Training techniques, optimization, and regularization
- Popular architectures (ResNet, VGG, Inception, etc.)
- Object detection and segmentation
- Generative models
- 3D vision, graph neural networks, and robot learning

**Resources:**
- [Course Website](https://cs231n.stanford.edu/index.html)
- [GitHub Repository](https://github.com/cs231n/cs231n.github.io)
- [Python NumPy Tutorial](https://cs231n.github.io/python-numpy-tutorial)
